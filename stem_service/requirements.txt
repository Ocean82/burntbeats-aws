# Running against a system/user Python that has torch>=2.6 installed will break
# 4-stem fast splits even though demucs_entry.py patches torch.load, because the
# patch runs in the subprocess Python — if that Python is not the venv Python,
# the patch is applied to the wrong torch installation.
#
# PyTorch 2.6+ defaults torch.load(weights_only=True). Demucs loads htdemucs checkpoints with
# pickle (HTDemucs class); unpickling fails unless weights_only=False. demucs_entry.py patches
# torch.load to inject weights_only=False + safe_globals allowlist, but this only works when the
# subprocess uses the venv Python (sys.executable).
# Keep torch/torchaudio on the same minor and <2.9 so wheels resolve together and load/save paths
# avoid torchcodec issues on some hosts (WSL/CI).
