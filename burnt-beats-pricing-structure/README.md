# Burnt Beats — pricing structure site

Standalone **Vite + React** app meant for **pricing transparency**:

- Separate from the authenticated stem editor landing page  
- Helps **pay‑as‑you‑go** visitors (single-track purchase, **`$5` top‑up** tokens, etc.) see current numbers **without signing in**, then funnel toward subscriptions  

**Deploy:** See **`docs/DEPLOY-MARKETING-SITE.md`**.  

**Compose:** Not started by root **`docker-compose.yml`** — host / secondary origin or subdirectory deploy typical.
